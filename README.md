
# 🏎️ F1 Racing Analytics Dashboard

An interactive **Formula 1 (F1) Racing Analytics Dashboard** built with **Tableau** to explore driver performance, constructor results, race wins, pit stops, retirements (DNFs), qualifying performance, and weather-related race patterns.

## 📌 Project Overview

This project uses data visualizations to make F1 racing statistics easier to explore and compare. The Tableau workbook contains multiple dashboards and worksheets focused on race outcomes, driver and constructor performance, and other race factors.

## 🎯 Project Objectives

- Analyze driver performance and race wins.
- Compare constructor performance and points.
- Explore race wins across seasons and circuits.
- Investigate Did Not Finish (DNF) patterns.
- Examine driver consistency and qualifying-versus-finish performance.
- Explore pit-stop and weather-related analysis.

## 📊 Dashboards and Visualizations

The packaged Tableau workbook includes dashboards and worksheets such as:

- **F1 Overview / Page 1**
- **Race Wins by Driver**
- **Wins by Season**
- **DNF Analysis**
- **Driver Consistency Analysis**
- **Pit Stop Analysis**
- **Weather Impact Analysis**
- **Driver Performance**
- **Constructor Performance**
- **Constructor Points Comparison**
- **Qualifying vs. Finish**
- **Race Wins by Circuit**
- **Top Drivers by Wins**

*Dashboard names and available views may vary slightly depending on the workbook version.*

## 🛠️ Tools and Technologies

## 📁 Project File

- `F1 Racing Analytics Dashboard (1).twbx` — Tableau Packaged Workbook (`.twbx`), including the workbook and its referenced Excel dataset.

A `.twbx` file is a packaged Tableau workbook. Keeping the workbook packaged helps make the dashboard and its included data easier to share.

## 🚀 How to Open the Dashboard

1. Download or clone this repository.
2. Install **Tableau Desktop** or use a compatible Tableau application that can open `.twbx` files.
3. Open `F1 Racing Analytics Dashboard (1).twbx` in Tableau.
4. If prompted, allow Tableau to load the packaged data source.
5. Select a dashboard tab to explore the visualizations.
6. Use available filters, selections, and interactive elements to investigate the data.

## 🐙 Upload This Project to GitHub

1. Create a new repository on GitHub, for example `F1-Racing-Analytics-Dashboard`.
2. Add this `README.md` and the `.twbx` workbook to the repository.
3. Commit the files with a message such as `Add F1 Racing Analytics Tableau dashboard`.
4. Open the repository page and verify that both files appear.
5. If you want people to interact with the dashboard in a browser, publish it separately using **Tableau Public** if the workbook and dataset are suitable for public sharing. Then add the published dashboard URL to this README.

> **Important:** GitHub stores the workbook file, but it does not render an interactive Tableau dashboard directly on the repository page. Publish the workbook to Tableau Public (or an appropriate Tableau Server/Cloud environment) for browser-based viewing. Check data licensing and privacy before publishing publicly.
